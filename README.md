# DukaFlow AI

An AI order desk for Kenyan wholesalers: retailers order by chat or by sending a photo of a handwritten list; an agent reads it, checks stock, quotes in KSh, and the wholesaler approves.

Built for **JacHacks Kenya 2026** (Jaseci Labs). All code in this repository was written during the event window (started Fri 16 Oct 2026, 17:00 EAT).

- **Language and toolchain:** Jac `0.37.25` (pinned in `jac.toml`).
- **AI assistance disclosure:** this project is developed with an AI coding assistant (Claude Code) working alongside the team. Planning documents were written before the event as brainstorming; the code was not.

_Full documentation (architecture, how to run, Jac and Jaseci usage, demo) is added as the build progresses._
